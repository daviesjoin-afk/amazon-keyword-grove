# Keyword Grove v0.3.2

发布日期：2026-09-03

这是 v0.3.1 发布后的数据统计补丁版本。

## 修复

- 产品概览、产品中心和侧边栏的关键词总量、强匹配数量按唯一关键词 ID 统计。
- 同一关键词在多个竞品 ASIN 中出现时，来源 ASIN 仍独立去重，但不会再把关键词总量按来源行重复计算。
- 关键词总量、MiMo 审核总数和广告建议进度现在使用一致的统计口径。
