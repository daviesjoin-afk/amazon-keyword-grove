# Keyword Grove v0.3.1

发布日期：2026-09-03

## 本次发布

本版本把网页端 GPT 已完成的 application-grade 仓库维护、并发语义审核 v2 与本地连续收集的产品状态/审核进度修复合并到主分支。

### 语义审核与广告建议

- MiMo v2.5 支持全量和增量审核；增量审核以后台任务运行，提供可查询状态，显示已审核/总数、待审核数、批次完成数和失败批次。
- 默认按 40 条一批、4 路并发（上限 8 路）调用模型；只并发网络请求，SQLite 决策仍按原批次顺序单线程写入。
- 成功批次立即持久化，失败批次保持待审核，重复点击不会创建第二个任务，刷新页面后可以继续查看进度并重试。
- 相关性显示使用竞品 ASIN 覆盖率（例如 `5/20`），语义相关度保留独立 0–100 分；低于 30% 覆盖率、低搜索量或过宽语义不会直接进入精准投放。
- 广泛投放只保留完整产品核心词根；`room decor` 等泛装饰查询只建议否定精准，不会把 `room` 单词根误判为否定词组。

### 产品与导入稳定性

- 空产品在上传标题/五点但尚未导入关键词表时，不再虚构 20 个竞品 ASIN、关键词或 MiMo 审核进度。
- 有效 SellerSprite 导入后产品从“准备中”转为可用；空表/表头错误不会伪造就绪状态。
- 多行更新会合并同一关键词的来源 ASIN，保留异常原始指标；人工锁定字段不被重新导入或语义审核覆盖。
- 产品选择在刷新后保持不变，异步切换请求不会把旧产品数据覆盖到新产品，空词库概览不再出现 `NaN%`。
- 关键词、词根、广告建议和 CSV 导出默认按月搜索量降序排列。

### 工程质量与安全

- 纳入 API Client、AI 设置安全和后台进度回归测试；后端增加编译、依赖完整性和版本一致性门禁，前端执行真实 Vitest 与 Vite production build。
- 纳入 API 支持层/AI transport 拆分、架构与贡献文档、PR 模板、最小 CI 权限、并发任务取消、超时和分组 Dependabot 配置。
- API Key 只返回脱敏提示；MiMo 仅提供辅助审核，所有广告动作仍是人工审批草稿，不连接 Amazon Ads。
