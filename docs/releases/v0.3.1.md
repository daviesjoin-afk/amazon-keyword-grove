# Keyword Grove v0.3.1

发布日期：2026-09-03

## 发布概要

本版本完善了关键词语义审核、广告建议、产品导入与数据统计的一致性，并强化了本地数据与 API 凭据的安全边界。

### 语义审核与广告建议

- AI 语义审核支持全量与增量审核；增量任务提供可查询状态，显示已审核数、待审核数、处理进度及失败项。
- 审核结果在每个处理单元完成后持久化；失败项保留待审核状态，支持后续增量重试。
- 重复提交不会创建重复审核任务；刷新页面后可恢复任务状态并继续查看进度。
- 相关性显示使用竞品 ASIN 覆盖率（例如 `5/20`），语义相关度保留独立 0–100 分；低于 30% 覆盖率、低搜索量或过宽语义不会直接进入精准投放。
- 广泛投放只保留完整产品核心词根；`room decor` 等泛装饰查询只建议否定精准，不会把 `room` 单词根误判为否定词组。

### 产品与导入稳定性

- 空产品在上传标题/五点但尚未导入关键词表时，不再虚构 20 个竞品 ASIN、关键词或 AI 审核进度。
- 有效 SellerSprite 导入后产品从“准备中”转为可用；空表/表头错误不会伪造就绪状态。
- 多行更新会合并同一关键词的来源 ASIN，保留异常原始指标；人工锁定字段不被重新导入或语义审核覆盖。
- 产品选择在刷新后保持不变，异步切换请求不会把旧产品数据覆盖到新产品，空词库概览不再出现 `NaN%`。
- 关键词、词根、广告建议和 CSV 导出默认按月搜索量降序排列。

### 工程质量与安全

- 完善 API、AI 设置与审核进度的回归测试，并加强持续集成中的构建、依赖完整性与版本一致性检查。
- 补充架构说明、贡献规范与拉取请求检查清单，优化持续集成权限、任务超时与依赖更新策略。
- API Key 只返回脱敏提示；AI 仅提供辅助审核，所有广告动作仍是人工审批草稿，不连接 Amazon Ads。

## 验证结果

- 后端回归测试通过，包含 API、导入、规则与审核进度场景。
- 前端单元测试与生产构建通过。
- 发布前完成差异检查；公开仓库不包含真实 SellerSprite 文件、本地数据库、运行日志或 API Key。
